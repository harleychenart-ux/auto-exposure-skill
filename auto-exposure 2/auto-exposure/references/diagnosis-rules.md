# 曝光诊断口径与阈值

## 1. 指标定义（全部在 sRGB 显示域，0–1）

| 指标 | 含义 | 用途 |
| --- | --- | --- |
| `mean` | 全图亮度均值（Rec.709 权重） | 判断整体明暗，是最主要的判据 |
| `median` | 亮度中位数 | 抗局部高光/大面积暗部干扰，判断“主体”是否偏暗 |
| `p05 / p95` | 5%/95% 分位 | 黑白场位置，`contrast = p95 - p05` 反映反差 |
| `clip_high` | **三通道同时 ≥ 0.985** 的像素占比 | 真正的“死白”：所有通道都到顶，细节不可恢复 |
| `clip_any` | 任一通道 ≥ 0.995 的像素占比 | 单通道溢出（如只有红通道爆掉） |
| `clip_low` | **三通道同时 ≤ 0.015** 的像素占比 | “死黑”，暗部被压到 0 |
| `shadow_share` | 亮度 < 0.15 的占比 | 暗部规模，决定提亮力度 |
| `highlight_share` | 亮度 > 0.90 的占比 | 是否存在高光亮斑，用于夜景判别 |
| `grid` / `worst_blocks` | 3×3 分块均值与死白率 | 判断是局部问题（天空爆、主体正常）还是全局问题 |

**为什么用“三通道同时到顶”而不是“任一通道到顶”**：单通道到顶往往只是色彩偏移（如红色饱和），
补回来仍有层次；三通道全到顶才是真正的信息丢失。这个指标决定了“能不能用本地校正救回来”。

## 2. 判定规则（`classify()` 实现）

按顺序命中，先命中先归类：

| 条件 | 判定 | 严重度 | 说明 |
| --- | --- | --- | --- |
| `clip_high ≥ 5%` 且 `mean ≥ 60%` | `overexposed` | `severe` 若 `clip_high ≥ 12%` 或 `mean ≥ 75%`，否则 `moderate` | 整体过曝 |
| `clip_high ≥ 2%` 且 `mean < 45%` | `backlit` | `severe` 若 `clip_high ≥ 15%` 或 `mean ≤ 15%` | 逆光/大光比：高光爆 + 中间调暗 |
| `mean ≤ 30%` 或 `median ≤ 22%` | `underexposed` | `severe` 若 `mean ≤ 16%` | 欠曝 |
| `contrast < 30%` 且 `30% < mean < 78%` | `low_contrast` | `moderate` | 发灰、雾感 |
| `mean ≥ 55%` 且 `clip_any ≥ 5%` | `slightly_over` | `light` | 接近临界 |
| 其余 | `ok` | `none` | 正常；`clip_high ≥ 1%` 时附注小面积高光溢出可接受 |

> 逆光阈值取 2%：2% 的三通道死白已经排除了灯泡、反光这类零星亮斑，却足以抓住
> "窗外过曝 + 室内剪影"这种典型大光比；取 5% 会把它们误判成普通欠曝，然后按"提亮"处理，
> 结果窗户被推得更白（实测：咖啡店窗景 4.3% 死白 + 均值 23%，旧规则判欠曝）。

**夜景保护**：`mean < 35%` 且 `highlight_share > 1.5%` 且 `clip_high < 2%`（画面有真实亮斑、但没有成片死白）时，目标亮度降到 34%，
避免把夜景提亮成灰白天。若整片偏暗且几乎没有亮斑，则按普通欠曝处理（说明是欠曝而非夜景）。

## 3. 目标亮度（`plan_correction()`）

| 判定 | 目标 `mean` | 高光肩部 `shoulder` | 反差增益 |
| --- | --- | --- | --- |
| 过曝 severe | 50% | 0.55 | 0 |
| 过曝 moderate | 52% | 0.40 | 0 |
| 逆光 | 42% | 0.75 | 0.10 |
| 欠曝（普通） | 47% | 0.20 | 0.05 |
| 欠曝（夜景） | 34% | 0.20 | 0.05 |
| 低反差 | 47% | 0.25 | 0.16 |
| 轻微过曝 | 55% | 0.35 | 0 |

参考基准：中性灰（18% 反射率）在 sRGB 下约为 46%，所以 46–50% 是“正常曝光”的落点。

**目标亮度是可达上限，不是承诺**：上表是按“理想画面”给的目标，但一张屋里拍窗的照片，
全局均值硬拉到 42% 只能靠把窗户推成纯白。所以 `calibrate_plan()` 会先在小图上逐档加 EV，
一旦死白开始增长就停下，把目标下调到那个可达值（只降不升，下限 30%，并标注
`target_limited`）。验收也随之按这个可达目标判定——否则等于要求一张物理上做不到的图。

## 4. 数字背后的物理限制（必须如实告知用户）

- **死白区域（`clip_high`）在 8bit 图里已经等于 255，数据不存在**。任何曲线、LUT、局部映射都无法
  “找回层次”，本地校正最多把它压成一片均匀浅灰。要真正恢复被烧白区域的细节，只能靠**生成式重绘**
  （模型按语义猜出云层/皮肤/织物纹理），这也是本 Skill 主路径选方舟生图模型的原因。
- **死黑同理**。若 `clip_low` 很高，提亮后会出现色块、彩噪，要保守。
- **欠曝片的暗部通常仍有数据**（只是量化台阶粗），本地提亮能真实恢复，代价是放大噪点；提亮超过
  +3 EV 时噪点会明显，应在报告里提示“建议配合降噪”。
- **JPEG 压缩痕迹**会在强提亮时放大成方块噪，报告需注明。
