# 生成式曝光校正的提示词配方

`exposure_lib.build_prompt()` 会按诊断结果自动拼装，一般**不要手改**。理解它的结构是为了在
验收不通过时知道该改哪一句。

## 1. 五段式结构

```
① 任务限定    对这张照片做【曝光校正】，只调整光照与明暗，绝不重绘画面内容。
② 现状描述    当前问题：<判定>（平均亮度 X%、三通道死白 Y%、死黑 Z%）。
③ 目标        把整体压回/提亮到约 N% 的中性曝光，<该判定的专属要求>。
④ 保留清单    构图与裁切、视角、人物身份与五官、物体形状与位置、文字、白平衡色温、
              景深、颗粒质感。
⑤ 禁止清单    增删元素、替换美化人物、改肤色材质、滤镜/HDR 光晕、改比例、AI 水印。
```

**②为什么一定要写数字**：模型对“太亮了”“过曝”这种词的理解是发散的，写“平均亮度 15%，需要提到
约 47%”能显著提升方向正确率。

**③的“专属要求”按判定变化**，这是决定成败的一句：

| 判定 | 专属要求 |
| --- | --- |
| 过曝 | “重点找回被烧白区域（天空/高光/皮肤高光）的层次与渐变，**不要整体发灰**” |
| 逆光 | “高光收回 + 主体提亮”双向都写，否则模型只做一边 |
| 欠曝 | “暗部要有层次、不能糊成一片灰，噪点不要放大成彩噪” |
| 低反差 | “拉开黑白场、去灰雾感，但高光不能过曝” |
| 夜景 | “允许保留夜色氛围，不要提亮成白天” |

## 2. 距离控制（避免“修图修成另一张图”）

模型天生想“重绘得更漂亮”。三条约束按重要性排序：

1. **禁止项写在最后**（模型对末尾指令更敏感），且用否定句。
2. 显式列出「保留清单」，把“不许动”的对象具体化（文字、身份、构图），比抽象说“不要改”有效。
3. 需要更强约束时，在开头加一句：`这是一张纪实照片，只做曝光校正，任何内容变化都视为失败。`

## 3. 失败重试的升级顺序（`pipeline.py` 自动处理第 1 档）

| 档 | 触发 | 动作 |
| --- | --- | --- |
| 0 | 首次 | 标准提示词 |
| 1 | 结构分 < 0.62 / 清晰度掉太多 | **不再重试**，直接回退本地确定性校正（保内容优先） |
| 2 | 亮度没到位（status=partial） | 用 `--target` 指定更保守的目标后重跑；或加大 `shoulder` |
| 3 | 死白仍在 | 属正常限制，写进报告，不反复烧钱重试 |

> 生成式重绘有随机性，**同一张图最多重试 1 次**；结果仍漂移就承认它做不到，交付本地版并说明原因。

## 4. 送图前的归一化（`pre_normalized`）

极端欠曝（`mean ≤ 14%`）或重度死白（`clip_high ≥ 20%`）时，模型看到的几乎是黑屏/白屏，
容易瞎猜。此时先做一次轻度本地归一化（目标 33% / 62%）再送图，并在提示词里注明
「输入图已做轻度自动归一化，请在此基础上还原自然光比」。

这不会污染结果——它只是把“不可判读”变成“可判读”。

**实测补充（极端泛白）**：`mean ≥ 85%` 但 `clip_high < 20%` 的“整幅发白”不属于死白，
归一化阈值不会触发，实测直接用原图送模型即可正常重建（样张：平均 91.6%、p01 60%，
输出 59.8%、p01 4.9%、结构 0.80 通过）。这类图的提示词必须点明具体物体要恢复成什么样
（树冠→深绿枝叶、草地→草尖与投影、长椅→木条缝隙），只写“压暗”会让模型把整片压成灰。

## 5. 输出尺寸

- 默认 `size: "2K"`：足够交付，且比 4K 便宜。
- **按长边等比缩放，不要固定宽度**：竖图（如 1600×2848）固定宽度 2048 会算出 3646 高，
  超出模型上限。正确做法是长边压到 2048（1600×2848 → 1151×2048）。
- 输入图很小（< 1000px）时不建议直接 2K，会明显涂抹；可先用本地插值到 2K 再送。
- 模型可能返回略微不同的宽高比；验收里 `aspect_delta > 3%` 会判定为“被裁切/补边”，需重跑或裁剪对齐。

## 6. 不适合走生成式的情况

- 证件、票据、扫描件、UI 截图、含小字的海报 → 文字会被重绘出错字，**必须用本地校正**。
- 商品图需要像素级一致（白底、logo、刻度）→ 用本地校正。
- 人像特写且身份敏感 → 生成式有换脸风险，验收 `structure < 0.62` 会自动拦下，但优先本地。
